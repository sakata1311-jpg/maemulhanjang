매물한장 — Windows 프로그램

1. 이 폴더의 MaemulHanjang.exe를 실행하세요.
2. 처음 실행 시 Windows SmartScreen이 표시되면
   "추가 정보" → "실행"을 눌러 주세요.
   (서명되지 않은 개인 제작 프로그램이라 표시될 수 있습니다.)
3. 앱 오른쪽 위의 "이용권 구매"를 눌러 받은 라이선스 키를 입력합니다.
   - STANDARD: 30일
   - DELUXE: 60일
   - PREMIUM: 90일
4. 매물 정보와 사진을 넣고 카드뉴스·A4 전단지를 저장합니다.
   - 저장한 파일은 기본적으로 PC의 "다운로드" 폴더에 저장됩니다.
   - A4 전단지는 JPG로 저장한 뒤 인쇄하거나 인쇄소에 전달하세요.

- Windows 10/11 64비트
- 인터넷 연결 없이 사용 가능
- 매물 정보와 사진은 PC에만 저장됩니다.
- 실행되지 않으면 Microsoft Edge WebView2 Runtime이 설치되어 있는지 확인하세요.
  (Windows 10/11에는 대부분 기본 설치되어 있습니다.)
