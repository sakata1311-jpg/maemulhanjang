| 파일 | 용도 |
|---|---|
| `instagram-30days.md` | 인스타 30일 캘린더 + 캡션 |
| `community-posts.md` | 네이버 카페·커뮤니티 게시글 5종 |
| `outreach.md` | 중개사·제휴처 DM/이메일/전화 스크립트 |
| `keywords.md` | SEO 키워드 50선 + 콘텐츠 매핑 |
| `email-templates.md` | 구매·라이선스·환불·후기 이메일 |
| `launch-checklist.md` | 출시 첫 7일 체크리스트 |

## 톤앤매너

- 과장하지 않는다. “1분”, “무제한”, “평생”처럼 사실과 다르거나 보증으로 읽힐 표현은 쓰지 않는다.
- 중개사의 시간을 아껴준다는 관점.
- “매물 자랑”이 아니라 “홍보 노동을 줄이는 도구”.
- 경쟁 도구(Canva 등)를 깎아내리지 않는다. “Canva는 디자인 도구, 매물한장은 매물 홍보 조립기”.
- 광고 표기·법적 책임은 사용자에게 있음을 필요할 때 안내.

## 필수 해시태그 세트

```
#공인중개사 #부동산중개사 #부동산마케팅 #매물홍보 #부동산전단지 #매물전단지 #부동산카드뉴스 #카드뉴스제작 #부동산인스타 #중개사무소 #매물한장 #부동산SNS
```

> 인스타는 해시태그 5~10개가 적당합니다. 지역명을 1~2개 넣으면 노출에 유리합니다.
