## 3. 지역 키워드 (확장)

`[지역] 부동산 전단지`, `[지역] 매물 카드뉴스`, `[지역] 공인중개사 인스타`
예: 성산동, 망원동, 마포구, 서울, 분당, 수원, 부산.

- 지역별로 글을 양산하기보다, **실제 예시 매물**이 있는 지역 3~5곳부터.
- “지역 + 아파트명 + 평형 + 매매/전세”는 경쟁이 낮고 전환 의도가 높음.

## 4. 콘텐츠 클러스터

```
[허브] 부동산 전단지 만들기
 ├─ 필수 표기 체크리스트
 ├─ A4 300dpi 인쇄 가이드
 ├─ QR 코드 활용
 └─ 템플릿 6종 비교

[허브] 공인중개사 인스타 마케팅
 ├─ 카드뉴스 3장 구성
 ├─ 캡션·해시태그
 ├─ 릴스/숏폼
 └─ 매물 문구 예시

[허브] 매물 문구
 ├─ 아파트
 ├─ 빌라/주택
 ├─ 상가/사무실
 └─ 문자·블로그 채널별 길이
```

## 5. 글쓰기 템플릿

1. **결론**: “이 글에서 알 수 있는 것” 3줄
2. **문제**: 중개사가 겪는 구체적 상황
3. **해결**: 단계별 방법 (스크린샷/예시)
4. **주의**: 광고 표기·개인정보·과장 표현
5. **CTA**: 무료 도구/템플릿/가이드
6. **내부 링크**: 관련 글 2개 + 도구

## 6. 측정

- Google Search Console: 노출↑ 클릭률 낮은 글 제목 수정
- 네이버 서치어드바이저: 상위 노출 키워드 확인
- 2주마다: 상위 3개 글의 도입부/CTA 업데이트
- 3개월마다: 순위 없는 글은 통합/삭제
