# 인스타그램 30일 캘린더

하루 1개, 주 3~4회만 올려도 충분합니다. 이미지가 없으면 앱에서 만든 표지/전단지 캡처를 사용하세요.

## 1주 — 문제 제기 + 도구 소개

**Day 1. 매물 사진만 올리고 있지 않나요?**
- 이미지: 매물 사진 1장 vs 카드뉴스 3장 비교
- 캡션:
  ```
  매물 사진만 올리면 스크롤에 묻힙니다.
  표지-정보-연락처 3장으로 나누는 것만으로도 저장과 문의가 달라집니다.
  오늘 매물, 1분 만에 카드뉴스로 만들어보세요.
  ```
- CTA: 프로필 링크 → 무료로 만들기
- 해시태그: #공인중개사 #부동산마케팅 #매물홍보 #부동산카드뉴스

**Day 2. 전단지 만드는 데 30분 쓰고 있나요?**
- 이미지: 전단지 before/after
- 캡션: “가격·면적·층 넣고 템플릿 고르면 끝. A4 300dpi까지 한 번에.”

**Day 3. 카드뉴스 3장 구성법**
- 이미지: 표지/정보/연락처 3장
- 캡션: 각 장의 역할 설명 + “표지에 가격·면적·지역 중 하나는 꼭.”

**Day 4. 무료로 써보세요**
- 이미지: 앱 화면 + “무료”
- 캡션: “회원가입 없이, 설치 없이. 샘플 매물로 1분 체험.”

**Day 5. 이런 문구, 쓰고 있지 않나요?**
- 이미지: “급매/최저가/무조건” vs “즉시 입주/남향 3층”
- 캡션: 과장 표현 대신 비교 가능한 사실로.

**Day 6. 중개사 정보, 어디에 넣나요?**
- 이미지: 전단지 하단 표기 확대
- 캡션: 사무소명·등록번호·연락처 자동 표기.

**Day 7. 주간 정리**
- 이미지: 카드 3장 세트
- 캡션: “이번 주 매물, 카드뉴스로 정리해보세요.”

## 2주 — 사용법 + 신뢰

**Day 8. 1분 데모 (릴스)**
- 화면 녹화: 정보 입력 → 템플릿 → 저장
- 캡션: “복잡한 편집 없이, 매물 정보만.”

**Day 9. 사진 잘 찍는 법 3가지**
- 이미지: 세로 사진/자연광/개인정보 체크
- 캡션: “휴대폰 세로로, 창가 빛으로, 서류·얼굴은 가리고.”

**Day 10. 템플릿 6종 소개**
- 이미지: 6개 커버 콜라주
- 캡션: “아파트는 시티, 빌라는 선셋, 급매는 모노.”

**Day 11. A4 전단지 인쇄 팁**
- 이미지: 인쇄 설정 화면
- 캡션: “A4·여백 없음·배경 그래픽 켜기.”

**Day 12. 광고 표기 체크리스트**
- 이미지: 체크리스트 6개
- 캡션: “사무소명·등록번호·가격·사진 정확성 확인.”

**Day 13. 문자 문구 예시**
- 이미지: 문자 말풍선
- 캡션: “가격·면적·연락처를 한 줄에. 캡션 복사해서 문자로.”

**Day 14. 고객 후기/피드백**
- 이미지: 후기 캡처(동의 받은 것)
- 캡션: “실제 중개사가 이렇게 씁니다.”

## 3주 — 사례 + 비교

- 캡션: “보증금·월세·관리비·면적을 한 장에.”
