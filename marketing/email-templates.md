# 이메일 템플릿

> `[ ]` 부분을 실제 값으로 바꿔 사용하세요. 고객 이메일은 BCC가 아니라 개별 발송을 권장합니다.

---

## 1. 구매 문의 답변

**제목:** [매물한장] 이용권 안내

```
안녕하세요, [이름]님.
매물한장 이용권 문의 감사합니다.

이용권 (부가세 포함)
- STANDARD: 30일 9,000원
- DELUXE: 60일 17,000원 (우선 지원)
- PREMIUM: 90일 24,000원 (우선 지원)

포함: Windows 프로그램, 웹앱, 템플릿 6종, A4 300dpi, 1:1·스토리, 워터마크 제거, 사진 5장, ZIP 저장
환경: Windows 10/11 64비트, Chrome/Edge 최신 버전

결제는 크몽 상품 페이지에서 진행됩니다.
[크몽 상품 링크]

결제 확인 후 프로그램 ZIP과 라이선스 키를 크몽 메시지로 보내드립니다.

감사합니다.
매물한장 드림
```

## 2. 결제 확인 + 키 발급

**제목:** [매물한장] 이용권 키가 도착했습니다

```
안녕하세요, [이름]님.
결제 확인되었습니다. 감사합니다.

■ 이용권
[STANDARD 30일 / DELUXE 60일 / PREMIUM 90일]

■ 라이선스 키
MH1.[...]

■ 사용 방법 (Windows 프로그램)
1) 매물한장_프로그램_Windows.zip 압축을 풉니다.
2) MaemulHanjang.exe를 실행합니다.
3) 오른쪽 위 ‘이용권 구매’를 클릭합니다.
4) 위 키를 붙여넣고 ‘활성화’를 누릅니다.
5) ‘STANDARD 사용 중’처럼 표시되면 완료입니다.

■ 사용 방법 (웹앱)
1) 크몽 메시지로 안내드린 웹 주소를 엽니다.
2) 오른쪽 위 ‘이용권 구매’에서 같은 키를 입력합니다.

■ 참고
- 키는 PC에 저장됩니다. 프로그램을 다시 설치하면 키를 다시 입력해야 하니 보관해 주세요.
- 다른 기기에서도 같은 키를 입력해 사용할 수 있습니다.
- 매물 정보와 사진은 서버로 전송되지 않고 PC에만 저장됩니다.

사용 중 불편한 점은 언제든 알려주세요.
감사합니다.
매물한장 드림
```

```
편하게 알려주세요. 바로 도와드리겠습니다.

사용 후기나 개선 의견을 보내주시면 다음 업데이트에 반영하겠습니다.
감사합니다.
매물한장 드림
```

## 4. 후기 요청

**제목:** [매물한장] 짧은 후기 부탁드려도 될까요?

```
안녕하세요, [이름]님.
매물한장을 사용해 주셔서 감사합니다.

다른 중개사분들께 도움이 될 수 있도록
한 줄 후기와(가능하면) 결과물 스크린샷을 받을 수 있을까요?

- 사용 전: 매물 홍보에 걸리던 시간
- 사용 후: 달라진 점
- 추천하고 싶은 이유

후기는 [랜딩/인스타]에 익명 또는 상호명으로 소개할 수 있습니다.
원하지 않으시면 사용하지 않겠습니다.

감사합니다.
매물한장 드림
```
