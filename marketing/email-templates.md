# 이메일 템플릿

> `[ ]` 부분을 실제 값으로 바꿔 사용하세요. 고객 이메일은 BCC가 아니라 개별 발송을 권장합니다.

---

## 1. 구매 문의 답변

**제목:** [매물한장] Pro 라이선스 안내

```
안녕하세요, [이름]님.
매물한장 Pro 라이선스 문의 감사합니다.

Pro 평생 라이선스
- 가격: 29,000원 (런칭가, 정가 49,000원)
- 포함: 템플릿 6종, A4 300dpi, 1:1·스토리, 워터마크 제거, 사진 5장, ZIP 저장
- 사용 기간: 평생 (추가 결제 없음)
- 환경: Chrome/Edge 최신 버전

결제 방법
- [계좌이체: 은행 / 계좌번호 / 예금주]
- 또는 [결제 링크]

입금 확인 후 라이선스 키를 이메일로 보내드립니다.
세금계산서/현금영수증이 필요하시면 말씀해 주세요.

감사합니다.
매물한장 드림
[사이트 주소]
```

## 2. 입금 확인 + 키 발급

**제목:** [매물한장] Pro 라이선스 키가 도착했습니다

```
안녕하세요, [이름]님.
결제 확인되었습니다. 감사합니다.

■ 라이선스 키
MH1.[...]

■ 사용 방법
1) [사이트]/app.html 접속
2) 오른쪽 위 ‘Pro 업그레이드’ 클릭
3) 위 키를 붙여넣고 ‘활성화’
4) ‘PRO 사용 중’ 표시 확인

■ 참고
- 키는 브라우저에 저장됩니다. 브라우저 데이터를 삭제하면 다시 입력해야 하니 키를 보관해 주세요.
- 다른 기기에서도 같은 키를 입력해 사용할 수 있습니다.
- 매물 정보와 사진은 서버로 전송되지 않고 브라우저에만 저장됩니다.

사용 중 불편한 점은 언제든 알려주세요.
감사합니다.
매물한장 드림
```

**제목:** [매물한장] 잘 쓰고 계신가요?

```

지난번에 보내드린 매물한장은 사용해 보셨는지 궁금합니다.

혹시
- 사진 업로드가 어렵거나
- A4 인쇄 설정이 헷갈리거나
- 원하는 템플릿이 없으시면
편하게 알려주세요. 바로 도와드리겠습니다.

사용 후기나 개선 의견을 보내주시면 다음 업데이트에 반영하겠습니다.
감사합니다.
매물한장 드림
```

## 4. 후기 요청

**제목:** [매물한장] 짧은 후기 부탁드려도 될까요?

```

다른 중개사분들께 도움이 될 수 있도록
한 줄 후기와(가능하면) 결과물 스크린샷을 받을 수 있을까요?

- 사용 전: 매물 홍보에 걸리던 시간
- 사용 후: 달라진 점
- 추천하고 싶은 이유

후기는 [랜딩/인스타]에 익명 또는 상호명으로 소개할 수 있습니다.
원하지 않으시면 사용하지 않겠습니다.

감사합니다.
매물한장 드림
```
