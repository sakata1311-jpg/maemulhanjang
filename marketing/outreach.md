# 아웃리치 스크립트

> 스팸은 역효과입니다. 상대가 이미 아는 사람이거나, 커뮤니티에서 활동한 뒤 연락하세요.
> 첫 메시지는 “판매”가 아니라 “질문/도움”으로 시작합니다.

---

## 1. 지인 중개사 DM (1:1)

```
안녕하세요 대표님, 매물한장 만든 ○○○입니다.
요즘 매물 카드뉴스·전단지 만드는 데 시간 많이 쓰시는지 궁금해서 연락드렸어요.

매물 정보랑 사진만 넣으면 카드뉴스 3장, A4 전단지, 문자 문구가 1분 만에 나오는 도구를 만들었습니다.
설치나 회원가입 없이 브라우저에서 바로 됩니다.

혹시 괜찮으시면 무료 STANDARD 이용권으로 한 매물만 만들어보시고, 불편한 점 알려주실 수 있을까요?
피드백 주시면 바로 반영하겠습니다.
[링크]
```

**후속 (3일 뒤):**

```
안녕하세요, 지난번에 보내드린 매물한장입니다.
혹시 써보셨는지, 안 쓰셨다면 어떤 점이 망설여지는지 궁금합니다.
한 매물만 같이 만들어드릴 수도 있습니다. 편하실 때 알려주세요.
```

---

## 2. 지역 사무소 방문/전화

```
안녕하세요, 매물 홍보 도구를 만드는 ○○○입니다.
매물 사진과 정보만 넣으면 전단지·카드뉴스가 1분 만에 나오는 도구인데,
지역 사무소에서 실제로 쓸 수 있을지 의견을 듣고 싶어서 연락드렸습니다.

지금 바로 써보실 수 있게 무료 체험 키를 드릴 수 있습니다.
1분만 화면을 보여드려도 될까요?
```

- 방문 시: 노트북/태블릿으로 **그 사무소 매물 하나**를 즉석에서 만들어 보여주는 것이 가장 강력합니다.
- 명함/QR을 두고 오세요.

## 3. 커뮤니티 운영자/교육기관 제휴

```
안녕하세요, 매물한장 운영자 ○○○입니다.
공인중개사가 매물 정보만 넣으면 카드뉴스·A4 전단지·홍보 문구를 1분 만에 만드는 도구를 운영하고 있습니다.

회원님 채널/교육에서 “매물 홍보 실습” 도구로 소개해 주시면
- 회원 전용 할인 코드
- 판매 수수료 20~30%
- 교육용 샘플 매물/가이드 제공
을 제안드리고 싶습니다.

우선 무료 데모 링크를 보내드리고, 실제 사용 화면을 보신 뒤 결정하셔도 됩니다.
[링크]
```

**제휴 후보:**

- 공인중개사 실무 교육/연수
- 지역 중개사 네이버 카페
- 부동산 유튜브/블로그
- 사무소 인테리어·간판·명함 업체
- 부동산 CRM/사무관리 프로그램 (API 없이 링크 소개)

---

## 4. 인스타 DM (콜드)

```
안녕하세요, 대표님 계정에서 매물 카드뉴스 올리시는 걸 보고 연락드립니다.
매물 정보만 넣으면 카드뉴스 3장과 A4 전단지를 1분 만에 만들어주는 도구를 만들었습니다.
혹시 매물 올릴 때 디자인에 쓰는 시간이 아깝다고 느끼신 적 있으세요?
무료로 한 매물 만들어드려도 될까요?
```

- 첫 메시지에 링크를 바로 넣지 말고, 상대 반응 후 보냅니다.
- 하루 10~15건 이내, 같은 메시지 복붙 자제.

## 5. 이메일 (교육기관/블로그)

**제목:** 공인중개사 매물 홍보 실습 도구 제안 (무료 체험)

```
안녕하세요, 매물한장 운영자 ○○○입니다.

공인중개사를 위한 매물 홍보 도구를 소개드립니다.
매물 정보와 사진을 넣으면 인스타 카드뉴스, A4 전단지, 문자·블로그 문구가 1분 만에 완성됩니다.

- 웹앱은 설치·회원가입 없음, Windows 프로그램은 ZIP 실행
- 매물 정보는 PC에만 저장
- 무료 플랜 + 유료 이용권 STANDARD 30일 9,000원부터

교육/콘텐츠에 소개해 주시면 회원 전용 할인 코드와 판매 수수료를 드릴 수 있습니다.
10분 정도 데모를 보여드려도 될까요?

감사합니다.
○○○ 드림
[링크]
```

## 6. 거절/반론 대응

| 반론 | 대응 |
|---|---|
| “Canva로 충분해요” | “Canva는 디자인 도구고, 이건 매물 정보로 홍보물을 조립하는 도구입니다. 매물마다 반복하는 작업을 줄이는 데 특화되어 있습니다.” |
| “돈 내고 쓸 정도인가요?” | “카드뉴스 외주 1건이 보통 5만 원 이상입니다. 30일 9,000원이면 1건만 안 맡겨도 본전입니다.” |
| “사진이 서버에 올라가나요?” | “아니요, 브라우저에만 저장됩니다. 그래서 개인정보 걱정이 적습니다.” |
| “나는 컴퓨터를 잘 못해요” | “웹앱은 설치·회원가입이 없고, 프로그램은 압축을 풀고 실행만 하면 됩니다. 매물 정보만 넣으면 됩니다.” |
| “지금 바빠요” | “알겠습니다. 샘플 링크만 보내드릴게요. 시간 되실 때 1분만 봐주세요.” |

## 7. 하지 말아야 할 것

- 커뮤니티 규칙을 무시한 반복 홍보
- 상대 동의 없는 대량 DM/문자
- “월 1,000만 원 번다” 같은 허위 과장
- 후기·사용자 수를 지어내는 것
- 경쟁 도구를 비방하는 것
- 매물 정보·사진을 무단으로 예시로 쓰는 것
