# 크몽 등록 키트 — 매물한장 Pro

크몽 사이트에서 직접 확인한 내용을 기준으로 정리했습니다.
**카테고리: IT·프로그래밍 > 완성형 프로그램 스토어**

---

## 1. 결론: 이 카테고리가 맞는 이유

크몽의 `완성형 프로그램 스토어`에는 실제로 다음과 같은 **웹 기반 프로그램 이용권**이 판매되고 있습니다.

- 리뷰 답글 자동 비서 **월 이용권** (29,000원)
- 유튜브 영상 자동제작 **평생 이용권**
- 업무 자동화 프로그램/솔루션
- 완성형 프로그램 + 설치/세팅 상품

즉, “앱을 크몽에 업로드”하는 것이 아니라 **완성된 웹 프로그램의 이용권(라이선스)**을 판매하는 구조가 이미 존재합니다.

**전자책·템플릿** 카테고리는 PDF·템플릿용이므로 이 앱에는 맞지 않습니다.  
**일반 프로그램**은 주문제작 성격이 강하므로, 완성품 판매에는 `완성형 프로그램 스토어`가 가장 적합합니다.

---

## 2. 등록 전 확인 사항

- **개인 전문가**로 등록: 사업자등록 없이 시작 가능
- 휴대폰 본인인증 필요
- 서비스 심사: 영업일 기준 **최대 7일**
- 승인 후 **1차 카테고리 변경 불가** → 처음부터 661로 등록
- 크몽 서비스 설명·이미지에는 **외부 연락처/이메일/외부 링크 금지**
  - 앱 주소와 라이선스 키는 **구매 후 크몽 메시지**로 전달
- 메인 이미지: **652 × 488px (4:3)**, JPG/PNG, 유색 배경, 사방 50px 여백
- 메인 이미지에 **가격·할인·무료·최고/최저/1위** 표현 금지
- “100% A/S”, “무제한” 같은 보증 표현 금지
- 실행 파일 칸이 있으면 **사용 가이드 PDF**를 첨부
  - 웹앱이라 실행 파일이 없어도, 가이드 PDF로 대체 가능한지 심사 시 확인
  - 반려되면 크몽 1:1 문의로 “웹 기반 프로그램 이용권”임을 설명

## 4. 등록 순서

1. 크몽 로그인 → **전문가 등록**
2. **개인 전문가** 선택 → 휴대폰 본인인증
3. 프로필 작성
   - 프로필 사진, 소개, 전문 분야
   - “부동산 매물 홍보 자동화 도구 제작” 등
4. **마이크몽 → 내 서비스 → 서비스 등록**
5. 카테고리: `IT·프로그래밍 > 완성형 프로그램 스토어`
6. 제목/가격/작업일/수정 횟수 입력
7. 메인 이미지 `kmong-main.png` 업로드
8. 서비스 설명/FAQ 입력
9. 실행 파일 칸에 `maemulhanjang-pro-guide.pdf` 업로드
10. 제출 → 영업일 7일 이내 심사
11. 승인 후 상품 URL을 사이트 `checkoutUrl`에 연결
12. 주문이 들어오면 12시간 이내 키 발급·메시지 발송

## 5. 수수료·정산

- 크몽 판매 수수료: 대략 20% 안팎 (서비스 이용료 + 결제망 + VAT)
- 구매자에게는 별도로 결제 수수료 4.5%가 붙을 수 있음
- 29,000원 판매 시 판매자 수령액은 약 23,000원 전후
- 정산·세금 관련은 크몽 전문가센터/세무사 확인
- 개인 전문가는 사업자등록 전 판매 가능하나, **반복 매출 시 사업자등록 의무**가 생길 수 있음
- 통신판매업 신고: 직전 연도 50건 이상 + 매출 1억 400만 원 이상이면 대상

## 6. 반려 대비

- “웹앱이라 실행 파일이 없다” → 사용 가이드 PDF와 앱 화면 캡처를 첨부하고, “웹 기반 완성형 프로그램 이용권”이라고 설명
- “외부 링크/연락처” → 서비스 설명·이미지에서 모두 제거. 앱 주소는 구매 후 메시지로만.
- “가격/할인 표현” → 메인 이미지에서 가격 제거. 가격은 가격 필드에만.
- “보증 표현” → “100% A/S”, “무제한” 삭제. “7일 이내 오류 수정”으로 구체화.
- “카테고리 부적합” → `업무 자동화` 또는 `AI 자동화 프로그램`은 AI 기능이 없으므로 우선 661에서 설명 보강. 필요 시 크몽 1:1 문의로 카테고리 확인.

## 7. 첫 5건을 위한 운영

- 지인 중개사 5명에게 무료 Pro + 정직한 후기 요청
- 후기 3개가 쌓이면 가격을 29,000원 유지하거나 39,000원으로 소폭 인상
- 5건 후 `Deluxe` 패키지 추가:
  - 49,000원: Pro + 1:1 30분 세팅 + 템플릿 1종 추가
- 10건 후 `Premium`:
  - 99,000원: 3개 라이선스 + 1:1 세팅 + 우선 지원
- 크몽 메시지 응답은 1시간 이내를 목표
- 주문 후 12시간 이내 키 발급
